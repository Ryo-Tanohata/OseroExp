# AlphaZero の学習と対戦の記録

人間の棋譜・定石・評価関数を一切使わず、**ルールだけから自己対局で学習**した AlphaZero の記録です。

## 学習の設定

| 項目 | 内容 |
| --- | --- |
| ネットワーク | 残差ネット（64チャンネル × 4ブロック、約31万パラメータ）。出力は方策（65手の確率）と価値（勝ちやすさ） |
| 入力 | 手番側の石・相手の石・合法手の3枚（8×8） |
| 自己対局の探索 | 1手80回のモンテカルロ木探索（PUCT, c=1.5）。ルートにディリクレノイズ（α=0.5, ε=0.25）、最初の12手は訪問回数に比例して選ぶ |
| 学習 | 損失 (z−v)² − π·log p、Adam（学習率 1e-3 → 60回目から 3e-4、L2 1e-4）、盤の8対称で水増し、直近15万局面から学習 |
| 規模 | 105回 × 192局 = **自己対局 20,160局**、約3.5時間（CPU 4コア、GPU なし） |
| 実装 | 学習は Python + PyTorch（`train/`）。ブラウザでは同じネットと探索を JavaScript で実行（`js/alphazero.js`、PyTorch と誤差 1e-6 以下で一致） |

## 学習の損失

| 反復 | 自己対局 | 合計 | 価値 | 方策 |
| --- | --- | --- | --- | --- |
| 1 | 192 | 4.42 | 0.91 | 3.51 |
| 10 | 1,920 | 2.64 | 0.71 | 1.94 |
| 30 | 5,760 | 2.22 | 0.66 | 1.56 |
| 60 | 11,520 | 1.98 | 0.66 | 1.32 |
| 105 | 20,160 | 1.89 | 0.67 | 1.23 |

- 方策の損失は大きく下がり、「探索して選ぶ手」をネットの直感だけでかなり当てられるようになった
- 価値の損失は 0.66 前後で下げ止まるが、本気同士の自己対局の勝敗には偶然の要素もあるので、これは強さの物差しにはならない
- 60回目以降は損失の下がり方が小さく、このネットの大きさ・探索量では伸びが鈍っている

## 強さ：アプリ内蔵の αβ 探索AIとの対戦

AlphaZero は1手400回探索（ノイズなし）。先手・後手を交互にし、最初の4手はランダムにして局面を散らした。

| AlphaZero | 自己対局 | 対「普通」<br>(2手読み) | 対「強い」<br>(4手読み・残り10マス完全読み) | 対「最強」<br>(6手読み・残り12マス完全読み) |
| --- | --- | --- | --- | --- |
| 反復10 | 1,920局 | ― | 12勝1分7敗 (63%) | 2勝1分17敗 (13%) |
| 反復25 | 4,800局 | ― | 19勝1分0敗 (98%) | 14勝1分5敗 (73%) |
| 反復50 | 9,600局 | ― | 20勝0敗 (100%) | 15勝5敗 (75%) |
| 反復75 | 14,400局 | ― | 20勝0敗 (100%) | 19勝1分0敗 (98%) |
| **反復105（完成版）** | **20,160局** | **40勝0敗** | **40勝0敗** | **40勝0敗** |

完成版は内蔵AIの3段階すべてに 120戦全勝。
（比較相手はこのアプリの自作 αβ 探索AIです。Edax のような公開されている最強クラスのオセロソフトには及ばない可能性が高いです）

## 十分に強くなった AlphaZero 同士の対戦

1手800回探索。最初の4手はランダム（同じ対局の繰り返しを避けるため）。

| 対戦 | 結果（A から見て） | 色別 |
| --- | --- | --- |
| **完成版 A vs 完成版 B**（同じネット同士） | 9勝 5分 6敗 | 黒番3勝・引き分け5・白番12勝 |
| 完成版（反復105） vs 反復75 | 9勝 3分 8敗 | 黒番7勝・引き分け3・白番10勝 |
| 完成版（反復105） vs 反復10（1手400回） | **19勝 0分 1敗** | 黒番11勝・白番9勝 |

- 完成版同士は20局中5局が引き分け、石差0〜10の接戦が半分。2023年に発表された研究では、8×8オセロは双方が最善を尽くすと引き分けになると報告されており、強い者同士で引き分けや接戦が増えるのは自然な結果
- 反復75と完成版はほぼ互角で、学習後半の伸びが小さいことと一致する
- 学習初期（反復10）には19勝1敗で、学習による成長ははっきりしている

完成版同士の20局は、アプリの「対局の再生」でそのまま見られます（`models/showdown.js`）。

## ブラウザでの速さ

JavaScript での評価は1局面あたり約18ミリ秒（このクラウド環境の CPU 1コア。一般的なパソコンではもう少し速い）。

| 探索回数 | 1手の目安 |
| --- | --- |
| 100回 | 約2秒 |
| 200回（既定） | 約4秒 |
| 400回 | 約7秒 |
| 800回 | 約15秒 |

## もっと強くしたいとき

- 学習を延長する: `python3 train/train.py --hours 3 --resume`
- 自己対局の探索を増やす（`--sims 160` など）。1局あたりの時間は増えるが、学習データの質が上がる
- ネットを大きくする（`--channels 96 --blocks 6` など。最初から学習し直し。ブラウザでは遅くなる）
- GPU があれば同じ時間で数倍〜数十倍の自己対局ができる

## 再現の手順

```bash
pip install torch numpy
python3 train/train.py --hours 3.5                     # 学習（train/checkpoints/ に保存）
python3 train/evaluate.py ladder --iters 10 25 50 75 105 --levels 2 3 4 --games 20 --sims 400
python3 train/evaluate.py showdown --a 105 --b 105 --games 20 --sims 800 --js models/showdown.js
python3 train/export_model.py --iter 105 --name az      # ブラウザ用の重み（models/alphazero.js）
python3 train/export_model.py --iter 10 --name az-mid   # 学習途中の比較用
```

数値の元データは `train/results/` と `train/train_log.jsonl` にあります。
